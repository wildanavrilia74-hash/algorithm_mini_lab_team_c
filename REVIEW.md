-wildan review about bubble vs insertion-
Bubble Sort works by comparing two adjacent elements. If the left element is greater than the right element, they are swapped.
This process is repeated until the array is sorted.
For example, [5, 2, 8, 1, 4] becomes [1, 2, 4, 5, 8]. The main idea is compare and swap.
Insertion Sort works by taking one element as a key and comparing it with the elements before it.
Larger elements are shifted to the right, then the key is inserted into the correct position.
The main idea is take, shift, and insert.
The main difference is that Bubble Sort uses swapping, while Insertion Sort uses shifting and inserting. 
Both have an average time complexity of O(n²), but Insertion Sort is usually better for data that is already almost sorted.
